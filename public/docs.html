EV Tools & API

One guide to the Sportslab EV workbench, its 18 tools, the quote data contract, and the supplied local API archive.

Welcome to the Sportslab EV workspace

The workbench brings price comparison, expected value, arbitrage, fantasy, and tracking into one local workspace. Every tool below opens directly to its matching screen.

Workspace workflow

Start in Odds comparison. Add prices manually, import a version 1 workspace JSON file, or load clearly marked example records. Choose a sport and market, then move among tools without leaving the workspace.

Records are saved in this browser. Export a JSON copy to move them between browsers or machines. The calculation tools use the same saved records, so a price entered for comparison can also appear in Positive EV, arbitrage, low holds, and alert screens.

Quote data contract

Sportsbook quotes need a stable id, sport, event, market, type, line, side, book, American odds, live status, and an observation time ts. Exchange quotes can add exchange and liquidity. DFS props, prediction contracts, bets, results, and alerts have separate record arrays in the version 1 workspace format.

Positive EV requires a complete set of outcomes from another book at the same event, market, line, and live status. Live calculations exclude quotes older than 90 seconds. The detailed format is maintained in the project’s EV workbench data contract.

Markets

  • Odds comparison — compare entered prices and recorded movement.
  • Positive EV · pregame and Positive EV · live — compare offered odds with no-vig estimates from complete opposing books.
  • Arbitrage · pregame and Arbitrage · live — inspect opposing prices and calculated stake splits.
  • Middles — find spread and total pairs with an interval where both bets can win.
  • Low holds — compare the combined margin of opposing best prices.

Builders & research

  • Promo / bonus converter — balance a promotional side with a cash hedge.
  • Parlay builder — combine independent legs using saved fair probabilities.
  • Sharp money / Pro — inspect exchange liquidity, opposing prices, and movement history.

Fantasy tools

  • Fantasy lines — compare entered player lines and hit probabilities.
  • Fantasy optimizer — rank two-pick combinations against saved payout rules.
  • Fantasy slip builder — calculate hit-count distributions and projected payout.
  • Fantasy alerts — review newly entered props against local alert rules.

Records & alerts

  • Prediction traders — track contracts, order book snapshots, positions, and trades.
  • Bet tracker & CLV — grade saved bets and compare booked and closing prices.
  • Player prop trends — inspect entered results, hit rates, and paired-game relationships.
  • Movement & price alerts — manage thresholds and review local notifications.

Local API archive

The supplied EV tool folder is included as a local Python integration. Sportslab adds a normalized quote handoff so the quote-based EV screens can read the same local prices. The original scraper modules remain prototypes; POST /scrape responds with 501 until a working source adapter is supplied.

  • GET /api/ev/health and GET /api/ev/status — local service health and quote counts.
  • GET /api/ev/quotes — normalized sportsbook quotes for the workbench.
  • POST /api/ev/quotes — upsert a JSON array of normalized quotes.
  • GET /api/ev/matches — events represented by those quotes.
  • DELETE /api/ev/matches/{id} — remove an event and its quotes.
  • POST /api/ev/scrape?url=… — reserved for a future scraper; currently 501.

Connect the local API

Run the Python service on 127.0.0.1:8000 when it is available. The Sportslab Node app forwards the routes above to that local service; it does not expose them from the hosted site. Submit quotes using the data contract, then press Sync local API in the EV workspace. The workspace saves a local copy and shares those prices across its comparison, EV, arbitrage, builders, and alerts.

python integrations/ev_tool/run_server.py

For example, POST /api/ev/quotes accepts a JSON array like this:

[
  {
    "id": "feed:event:total:over:book",
    "sport": "NFL", "event": "Arizona vs Seattle",
    "market": "Game total", "type": "total", "line": 44.5,
    "side": "Over", "book": "Example Book", "odds": -110,
    "live": false, "ts": "2026-09-25T00:00:00Z"
  }
]

Manual and imported records remain available without the Python service. The quote sync does not populate fantasy props, prediction contracts, or personal bet records; those still use their own workspace records. The Sportslab API overview describes the app’s separate public preview routes.
